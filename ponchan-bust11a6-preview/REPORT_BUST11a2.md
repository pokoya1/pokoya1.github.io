# BUST-11a-2 v0.1｜手振り演出の先行試作
2026-11-27 / 親版 BUST-11a-1 v0.1

## 目的と範囲
新規切り出し待ちの間に既存素材で手振り演出を検証する。公開D-06、BUST-10c、11a-1の原本を変更しない。本編のステートマシンは変更せず、同じRendererを使う独立比較ページとして作成。左は10c expressive waveのmanifestと式から再現した動作曲線（発話、通常待機、既存二次動作を除外）、右は試作。左を完全な10c本編と見なさない。

## 実装
- wave-lab.html、js/wave-study.js、js/wave-ui.js、make_wave_single.py を追加。旧比較ラボは保持。両衣装を選択し同時刻A/B、低速、停止、時間スライダー、1/30秒ステップ、反復表示。既存の252 PNGとmanifestはそのまま。
- 3.72秒の比較時間を維持。新案：予備0.18 / 上げ0.78 / 手振り1.58 / 保持0.18 / 下げ0.82 / 余韻0.18秒。旧：上げ0.82 / 手振り1.80 / 保持0.22 / 下げ0.88秒。
- 視線を先行させ、頭の傾き・髪・眉を小さく連動。肩を支点とする合成腕全体の回転は最大0.70度、胴体回転は最大0.20度。これらは独立した肩の変形・骨格IKではない。
- 終端の独立手レイヤーは3拍の位相変化、滑らかな立ち上がりと減衰を使用。最大手首角度11.60→8.72度。240Hz数値サンプルの最大隣接角度差0.524→0.498度（実効fpsの指標ではない）。
- 中間姿勢の袖・手指は同じ合成PNGを使用。60–65%付近の形状差は未解決。新素材取得後に局所差分を作成して統合する。

## 検証
Chromium / Playwright、埋込単一HTMLをpage.set_contentで起動。252画像ロード。2衣装×2曲線×894サンプル=3,576件の状態・スロット解決、5,140件の参照素材存在チェック、範囲と有限値、開始終了パラメータゼロ、最大隣接姿勢スロット差1。実描画は2衣装各7時点の左右差、開始終了各2時点のピクセル一致を確認。再生・停止・コマ送り・自動停止を確認。JS例外0件。7本のJS構文チェック（親版からの5本と新規2本）。252 PNG・manifest・本編JS・旧ラボJSの親版とのバイト一致を確認。実時間での全フレームの美術評価、iPhone、実効fps、分離HTML、発話連動、録画・MP4は未検証。スクリーンショットは1.65秒時点のみ。新案の可愛らしさ・自然さは暫定評価であり、ユーザー承認・本編採用は未実施。

## 再現
ZIP展開後、python make_wave_single.py → wave-single.htmlをブラウザで開く。HTTP配信ならwave-lab.html（今回未検証）。qa/test_wave.pyにはPlaywrightとChromiumが必要。旧比較ラボはpython make_lab_single.pyで再生成。
